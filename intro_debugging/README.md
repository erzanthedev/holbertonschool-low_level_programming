# C - Intro to Debugging

Tasks on tracing and fixing logic errors in C using Python Tutor, compiled with `gcc -Wall -Wextra -Werror -pedantic -std=gnu89`.

## 0. Counting function
Fixes a loop and return value so the function sums 1 to n.

## 1. Nested loops
Fixes a nested loop that skipped values so the full multiplication table prints.
