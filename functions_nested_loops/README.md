# C - Functions, Nested Loops

## 0. _putchar
Prints `_putchar` followed by a new line using the `_putchar` function.

## 1. Alphabet
Prints the lowercase alphabet followed by a new line.

## 2. 10 x alphabet
Prints the lowercase alphabet 10 times, each followed by a new line.

## 3. islower
Checks whether a character is lowercase.

## 4. isalpha
Checks whether a character is a letter, lowercase or uppercase.

## 5. Sign
Prints the sign of a number and returns 1, 0 or -1.
