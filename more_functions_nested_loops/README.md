# C - More Functions, More Nested Loops

Tasks on functions and nested loops in C, written in Betty style and compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`.

## 0. isupper
Checks whether a character is uppercase.

## 1. isdigit
Checks whether a character is a digit (0 through 9).

## 2. Multiplication
Multiplies two integers and returns the result.

## 3. Print numbers
Prints the numbers from 0 to 9, followed by a new line.

## 4. Most numbers
Prints the numbers from 0 to 9, except 2 and 4.

## 5. More numbers
Prints the numbers from 0 to 14 ten times, each followed by a new line.

## 6. Line
Draws a straight line of underscores in the terminal.

## 7. Diagonal
Draws a diagonal line on the terminal.

## 8. Square
Prints a square of # characters of the given size.

## 9. Fizz-Buzz
Prints 1 to 100, using Fizz, Buzz and FizzBuzz for multiples of 3, 5 and both.
