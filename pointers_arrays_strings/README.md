# C - Pointers, arrays and strings

Practice with pointers, arrays and strings in C.

### 0. 98 Battery st.
`reset_to_98` sets the int a pointer points to, to 98.

### 1. Swap
`swap_int` swaps the values of two integers.

### 2. strlen
`_strlen` returns the length of a string.

### 3. puts
`_puts` prints a string followed by a new line.

### 4. Print reverse
`print_rev` prints a string in reverse, then a new line.

### 5. Reverse string
`rev_string` reverses a string in place.

### 6. puts2
`puts2` prints every other character, starting with the first.

### 7. puts half
`puts_half` prints the second half of a string.

### 8. Print array
`print_array` prints n ints separated by commas.

### 9. strcpy
`_strcpy` copies a string into a buffer and returns the buffer.

### 10. atoi
`_atoi` converts a string to an int.

## Part 2: strings, arrays and encoding

More string and array functions in C.

### 0. strcat
`_strcat` appends one string to another.

### 1. strncat
`_strncat` appends at most n bytes of one string to another.

### 2. strncpy
`_strncpy` copies a string, padding with null bytes up to n.

### 3. strcmp
`_strcmp` compares two strings like `strcmp`.

### 4. Reverse array
`reverse_array` reverses an int array in place.

### 5. string_toupper
`string_toupper` uppercases all lowercase letters.
